DROP YOUR LOGO HERE
===================

Add your AGESI / NEC logo to this folder. No code changes are needed —
the platform picks it up automatically the next time it loads.

  logo.png    Main logo. Appears in the sidebar on EVERY page, and beside
              the title on the home page.
              Recommended: ~400 x 120 px, transparent background (PNG).
              (.svg, .jpg, .webp also work.)

  icon.png    OPTIONAL small square icon for the browser tab.
              Recommended: 128 x 128 px square.
              If you don't add one, logo.png is used instead.

That's it. If neither file is present the app falls back to the 🌍 emoji
and shows no broken images.
